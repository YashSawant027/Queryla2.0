## 🚀 Queryla

AI-Powered Natural Language to SQL / NoSQL Query Platform

Queryla is a full-stack AI application that enables users to write plain English queries and instantly receive actual database results along with visual insights. It not only converts natural language into optimized SQL / NoSQL queries, but also executes them and displays the output as tables and graphs for better understanding and decision-making.

## ✨ Key Features

## 🧠 How Queryla Works

User enters a natural language query

Query is processed by the FastAPI NLP engine

NLP layer converts it into SQL or NoSQL

Query is executed on the selected database

Results are returned as:

✅ Actual data tables

📊 Auto-generated graphs & insights
